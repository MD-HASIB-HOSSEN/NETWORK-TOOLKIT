## 🌐 About The Project

HASIB NETWORK TOOLKIT is an Android-based network utility application that combines multiple networking, DNS, HTTP, Proxy, Host Discovery and Security Analysis tools in one platform.

## 🔥 Features & Tools

| # | Tool | Description |
|---|---|---|
| 01 | Network Dashboard | Internet, Wi-Fi and IP Information |
| 02 | DNS Lab | DNS Lookup and Record Analysis |
| 03 | DNS Tunnel Test | DNS Connectivity Testing |
| 04 | IP Hunter | IP Prefix and Authorized Range Search |
| 05 | Automatic Host Scanner | Automatic Host Discovery |
| 06 | Advanced Host Checker | Host, HTTP and SNI Testing |
| 07 | Bug Host Scanner | Security Misconfiguration Assessment |
| 08 | Bug Host Finder | Potential Issue Detection |
| 09 | Subdomain Finder | Subdomain Discovery |
| 10 | Host Compatibility Checker | DNS, HTTP and HTTPS Testing |
| 11 | HTTP Methods Lab | HTTP Method Testing |
| 12 | HTTP Response Checker | Server Response Analysis |
| 13 | HTTP Configuration Lab | Custom Host and SNI Configuration |
| 14 | Legacy Compatibility | Request Format Inspection |
| 15 | Payload Lab | JSON, XML and Encoding Tools |
| 16 | Header Analyzer | HTTP Header Analysis |
| 17 | SNI Checker | TLS and SNI Information |
| 18 | CDN Finder | CDN Provider Detection |
| 19 | Proxy Manager | HTTP, HTTPS, SOCKS4 and SOCKS5 |
| 20 | Server Response Analyzer | Response and Redirect Analysis |
| 21 | Port Checker | TCP Port Connectivity |
| 22 | Network Diagnostics | Network Troubleshooting |
| 23 | SSL/TLS Checker | Certificate and TLS Analysis |
| 24 | IP Information | IPv4, IPv6, ASN and ISP Information |
| 25 | History & Database | Save, Search and Export Results |
